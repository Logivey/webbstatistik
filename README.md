# Webbstatistik – Swede-Wheel & Hilfa

Statisk sida med webbstatistik från Google Analytics 4 (via Windsor.ai), publicerad med GitHub Pages.

- `index.html` – startsida med flikar
- `swede-wheel.html`, `hilfa.html` – en sida per bolag
- `data/sw/`, `data/hilfa/` – dagliga CSV-filer, uppdateras varje morgon av en schemalagd uppgift
